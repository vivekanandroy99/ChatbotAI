# Claude's notes (copied from the Windows PC)

Claude Code keeps its own notes about this project and its owner outside the project folder, so they don't travel with
git. This folder is a copy made on 2026-10-08 so another computer (the Mac) has them too.

On a new computer, ask Claude: "read docs/claude-memory and save these as your memory for this project". It copies them
into its own memory folder. MEMORY.md is the index.

The project's own notes - CLAUDE.md, memory.txt, MAC-SETUP.md - are read automatically and are the main source.
