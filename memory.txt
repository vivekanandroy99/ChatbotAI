PROJECT MEMORY - Offline Voice Companion (Unity)
================================================
For people and AI assistants picking up this project. Read this first, then CLAUDE.md (the detailed
technical brief - Claude Code loads it automatically). This file is the history: what changed, why,
and what it affected. ADD AN ENTRY AT THE TOP OF THE CHANGE LOG FOR EVERY CHANGE YOU MAKE.


1. WHAT IT IS
-------------
A 3D talking character for a portrait 2K/4K TV (also works on 16:9). You speak (English or Hindi), it
answers out loud and lip-syncs. Everything runs OFFLINE on the machine - no cloud APIs, ever.
Four bots, picked from the menu (top-right hamburger):
  Maya  (female) - Altcore/Altscape bot, answers ONLY from its documents, refuses off-topic questions
  Ethan (male)   - same knowledge as Maya
  Iris  (female) - "open chat": talks about anything with its own personality
  Leo   (male)   - "open chat"


2. HOW IT WORKS (one line per part)
-----------------------------------
Ears   : whisper.unity + ggml-large-v3-turbo (Unity-native). Detects English vs Hindi itself.
Brain  : LLMUnity + Gemma-3-4B (GGUF). Knowledge bots: router -> document search (bge-m3) -> answer from
         passages only -> grounding check. Hindi questions are answered in English, then translated.
Voice  : Python sidecar TTSServer/server.py on 127.0.0.1:8765 (Kokoro voices; Veena for Indian Hindi).
         Also hosts the document search. Unity starts/stops it (TTSProcessManager).
Body   : Reallusion CC4 actors (Assets/ActorCore Model/Actors), motions in Assets/ActorCore Model/Motion,
         built into Assets/Characters by tools/setup_four_bots.cs. Lip-sync = uLipSync, per-voice profiles.
Screen : UI Toolkit (Assets/UI/Companion + Scripts/UI/CompanionUI.cs, CompanionMenu.cs).
Scene  : Assets/Scenes/DialogueTest.unity.

Main folders:
  Assets/Scripts/{Dialogue,Audio,Avatar,UI}   the app's code
  Assets/Resources/Avatars                    the 4 bot profiles (voices, persona, mode, documents)
  Assets/KnowledgeDocuments/<bot id>          the documents a knowledge bot answers from
  Assets/StreamingAssets/Models               LLM + Whisper model files (ship with the build)
  TTSServer/                                  voice + document-search sidecar (Python venv in TTSServer/venv)
  tools/*.cs                                  editor scripts run with `unity command eval_file <file>`
  SpeechReview/<session>/                     every spoken sentence is recorded here (WAV + text) for review


3. HOW TO CHECK THINGS
----------------------
- Play the DialogueTest scene. Hold Space (or tap the mic) to talk. F1 = debug panel (timings, gate scores).
- Hear-back check of recorded speech: TTSServer\venv\Scripts\python.exe TTSServer\speech_check.py <session folder>
  (clarity % per sentence and unclear words; naturalness 1-5). Veena Hindi is normally ~78-82% clarity.
- "the voice fell behind" warnings in the Console = audio breaking (generation slower than playback).
- Motions: drop an export in Motion/<Idle|Talk><n>_<Male|Female>/ and re-run tools/setup_four_bots.cs.
  CC export: FBX, Unity 3D preset, Motion, Include Motion = Current Animation.


4. RULES THE OWNER HAS SET
--------------------------
- Fully offline at runtime. Ask before downloading anything.
- Dark mode is the default. Apple-like, clean UI. No bot name headline, no title bar.
- The bots never mention file names or "documents" in replies.
- Knowledge bots must not invent facts (the topic gate is the core product feature).
- Female motions only on female characters, male only on male.
- Owner likes Veena's Indian accent, but values clear pronunciation over accent.
- Keep answers to the owner short.

  * NOISE FILTER (SpeechInputController, Tunables "Background noise filter" + "Voice must stand out ... (dB)" 6): 100 Hz
    high-pass; ignored if the loudest 5% isn't >= 6 dB over the quietest 20% (or quieter than -50 dB); ignored if
    neither English nor Hindi is >= 25% likely; Whisper's silence inventions ("Thank you very much.", "Amen.", "you"...)
    ignored unless the voice was clearly there (>= 20 dB, -30 dB). Tested: noise -> nothing; speech, also with noise

  * AUTOMATIC LISTENING (menu > Visitors > Listening & language: Tap the button / Automatic; companion/listen-mode):
    mic open while CompanionUI.AutoAllowed (Ready, menu/sign-in/keyboard closed, 1 s after the bot spoke); own detector
    on 0.1 s chunks (MicrophoneRecord.OnChunkReady): voice = 3 chunks > room level x "Automatic: how loud a voice must
    be" (3) and > -46 dB; ends after "Automatic: pause that ends a question" (1 s) below max(room x ratio x 0.6, speaker
